# Prerequisites for Collateral AI

Work top-down. `/scaffold-project` needs only the **Local** section; `/infra-up` adds **Infra**;
deploying via GitHub Actions adds **Deploy**.

## 0. Accounts & one-time setup (manual — do these first)

- [ ] **GCP project(s)** created with **billing enabled**, your account = Owner/Editor.
      Split model: an **app project** (Cloud Run, Cloud SQL, GCS, …) and a **shared-infra project**
      for DNS/domain. You provide both project ids.
- [ ] **GitHub repository** for this monorepo (empty is fine): `gh repo create <owner>/<repo> --private`.
- [ ] *(Payments)* **Stripe** account → test + live secret keys; create a webhook endpoint → signing secret.
- [ ] *(Email)* **Resend** account → API key + a **verified sending domain**.
- [ ] *(Custom domain)* **Domain** purchased; a **Cloud DNS managed zone** in the shared-infra project;
      registrar nameservers pointed at that zone.

## 1. Local (for scaffolding + local run) — checked by `scripts/preflight.sh`

- [ ] Docker + Docker Compose v2 (daemon running)
- [ ] Node 20+ (24 LTS) + pnpm 9+
- [ ] Python 3.12+
- [ ] just
- [ ] **uv** + **cookiecutter** (Django backend is generated by real cookiecutter-django)
- [ ] Ports free: 3000, 8000, 5432, 4443

## 2. Infra (for `pulumi up`) — `scripts/preflight.sh --cloud`

- [ ] `gcloud` CLI, logged into the account that **owns the project**: `gcloud auth login`
- [ ] Application Default Credentials: `gcloud auth application-default login`
      (+ `gcloud auth application-default set-quota-project <app-project>`)
- [ ] `gcloud config set project <app-project>`
- [ ] Pulumi CLI (self-managed GCS backend — no Pulumi Cloud account needed)
- [ ] Cloud KMS API enabled (for the state key): `gcloud services enable cloudkms.googleapis.com`
      (the rest of the APIs are enabled by Pulumi)
- [ ] Run `deploy/bootstrap-state.sh` → creates the GCS state bucket + KMS key
- [ ] **Confirm sizing/cost** (Cloud SQL tier + HA, Cloud Run cpu/mem/min-instances) before `pulumi up`
- [ ] After `pulumi up`: paste **real secret values** into Secret Manager (they start as `REPLACE_ME`):
      `echo -n '<value>' | gcloud secrets versions add resend-api-key --data-file=-` (and stripe-*)

## 3. Deploy (GitHub Actions → Cloud Run)

- [ ] Code pushed to the GitHub repo
- [ ] **Workload Identity Federation**: a WIF pool + provider, and `github-cicd-sa` bound to your
      `owner/repo`. (Provisioned by Pulumi when `GITHUB_REPO` is set — see `deploy/env-template`.)
- [ ] **GitHub Actions secrets** set (most are Pulumi stack outputs — `scripts/set-github-secrets.sh`
      can populate them via `gh`):
      `GCP_PROJECT_ID`, `GCP_WIF_PROVIDER`, `CLOUD_SQL_CONNECTION_NAME`, `DJANGO_ALLOWED_HOSTS`,
      `DJANGO_ADMIN_URL`, `DJANGO_GCP_STORAGE_BUCKET_NAME`, `NEXT_PUBLIC_API_URL`, `NEXT_PUBLIC_SITE_URL`
- [ ] `gh auth login` (to set secrets / trigger workflows)

## Quick "am I ready?" check

```bash
bash scripts/preflight.sh            # local
bash scripts/preflight.sh --cloud    # + gcloud/pulumi/gh auth
```
